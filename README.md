# Leihbar

**Leihen statt kaufen.** Leihbar ist eine Plattform, auf der man Ausrüstung für Freizeit und Sport ausleihen kann – zum Beispiel Ski, Zelte, SUP-Boards oder E-Bikes. Auf einer Karte sieht man Angebote von Verleihgeschäften und von Privatpersonen in der Nähe oder am Urlaubsort.

Ein Projekt von Jonas und Jannis.

## Website

Die Seite ist eine Vorschau mit Beispieldaten. Man kann:

- Kategorien wählen (Ski, Wandern, Camping, Wassersport, Rad, Klettern)
- nach gewerblichen oder privaten Anbietern filtern
- Angebote in der Liste und auf der Karte sehen
- über die Suche zur passenden Kategorie springen

## Dateien

- `index.html` – die Seite
- `style.css` – das Design
- `app.js` – Beispieldaten und Funktionen (Kategorien, Filter, Karte)

Lokal ansehen: einfach `index.html` im Browser öffnen.
